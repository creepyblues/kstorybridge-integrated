## Recording Tips

### Before Recording
- Clear browser history/cookies for clean autocomplete
- Use a fresh account or test account for demo
- Have some titles already saved for the Saved video
- Test all flows once before recording

### During Recording
- Speak naturally, conversational tone
- Pause briefly between major actions (gives editing room)
- Move mouse smoothly and deliberately
- Wait for pages to load before narrating results

### Editing Suggestions
- Add subtle zoom on important UI elements
- Consider adding chapter markers for longer videos
- Include end card with "Subscribe" or next video link
- Add captions for accessibility

---

## Video Series Order (Recommended)

### For New Visitors (Pre-Signup)
1. **Free Trial** - Entry point for anonymous visitors
